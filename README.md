# pdt-chicago-crimes

Metadata for the [Crimes - 2001 to Present (City of Chicago)](https://data.cityofchicago.org/d/ijzp-q8t2), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** one release, the portal snapshot of 2026-11-19: 27 records in two tables (`crimes`, 22 columns; `iucr`, the code list, 5 columns). Terms not yet reviewed, so everything stays local. PublicDataToolkit Task 33.

## What the dataset is

Reported incidents of crime in the City of Chicago since 2001, from the Chicago Police Department CLEAR system, published on the Chicago Data Portal (Socrata) and updated daily. Not a survey: one row per incident, except homicides, which have one row per victim.

**A moving table.** The portal has no versions: rows are added and revised every day, and the columns' metadata can change at any time. So a release here is a dated snapshot. On one date, the build fetches the Socrata metadata, the IUCR code list, the portal's count of each column by year, and the rows for one data year (2024), and records each file's checksum. The release id is that date. The portal's change notes ("stories") are kept as sources.

## Terms of use

The City of Chicago's Terms of Use are at https://www.chicago.gov/city/en/narr/foia/data_disclaimer.html, and the portal labels the dataset's license "See Terms of Use". [`dataset.yaml`](dataset.yaml) quotes them. They haven't been reviewed by a person yet, so every term is `unknown` and nothing built from this repo may ship (STANDARD.md §8). The repo has no git remote, and the data stays in `data/`, which is gitignored.

## How to get the data

Every file comes from the portal's API: [`sources.yaml`](sources.yaml) lists each URL, where it goes in `data/raw/<release>/`, and its checksum on the snapshot date.

```bash
make download ARGS=--accept-terms   # after reading the terms
make data                           # data/processed/: the 2024 rows and the code list, in the common format
```

The portal changes daily, so a later download won't match the recorded checksums. That's expected: it's a new snapshot, and so a new release.

## How to use the metadata

- `metadata/releases/<release>/<table>/variables.jsonl`: one record per column of `crimes` and `iucr`. Each has the portal's label and description, verbatim, and its storage type. For `crimes`, it also has availability by year from the portal's own counts, with where each fact came from. `crimes/iucr` lists every IUCR code, active or retired, from the code list.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

Chicago Police Department. Crimes - 2001 to Present. City of Chicago Data Portal, dataset ijzp-q8t2. https://data.cityofchicago.org/d/ijzp-q8t2

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build    # the records, from data/raw/<release>/
make data     # the common-format data, for pdt check's data checks
make views
make check
```

`build/report.md` lists what the sources don't give: Socrata types the standard has no storage type for (`checkbox`, `location`), and `fbi_code`'s labels. The FBI code list the publisher links to now asks for a sign-in.
